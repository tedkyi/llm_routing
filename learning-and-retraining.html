How routing is built

Learning and Retraining

  • Simpler is to pre-train a router and use frozen model (offline learning)
  • Some papers examine algorithms that learn as you use models and provide preference data (online learning)
  • Another dimension is what happens when new LLMs become available
  • Most routers need to be retrained from scratch
  • Some, such as ones using clustering, only require the new model to be scored. The highest scoring model for each cluster is the best.
